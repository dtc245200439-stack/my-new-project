**NovaTask Workspace** là bài tập ứng dụng Web phong cách **Glassmorphism modern** giúp quản lý bài tập cá nhân, theo dõi tiến độ công việc trực quan bằng bảng Kanban, đồng hồ Pomodoro tập trung và biểu đồ năng suất Canvas.

---

## 🌟 Tính Năng Nổi Bật

- **📊 Dashboard Báo Cáo Năng Suất**:
  - Thống kê tự động tổng số bài tập, bài tập đã xong, bài tập đang thực hiện và tỷ lệ hoàn thành.
  - Biểu đồ đường năng suất theo tuần vẽ bằng HTML5 Canvas API với hoạt họa mượt mà.

- **📋 Bảng Quản Lý Bài Tập (Kanban Board)**:
  - 4 cột phân loại luồng công việc: *To Do*, *In Progress*, *Review*, *Completed*.
  - Thêm, xóa, chuyển đổi nhanh trạng thái bài tập với chỉ 1 click.
  - Tìm kiếm & lọc dữ liệu realtime theo tiêu đề hoặc danh mục.

- **⏱️ Đồng Hồ Tập Trung (Pomodoro Focus Timer)**:
  - Bộ đếm thời gian tập trung 25 phút, nghỉ ngắn 5 phút, nghỉ dài 15 phút.
  - Vòng tiến trình SVG động theo mốc thời gian thực.

- **📝 Ghi Chú & Ý Tưởng Bài Tập (Quick Notes)**:
  - Bảng ghi chú bài tập tương tác, lưu dữ liệu trực tiếp vào `localStorage`.

- **🎨 Chế Độ Giao Diện & Tối Ưu UI/UX**:
  - Chuyển đổi linh hoạt **Dark Mode** & **Light Mode**.
  - Hiệu ứng Ambient Glow, Glassmorphism, Micro-animations.

- **📦 Xuất Bài Tập (JSON Export)**:
  - Cho phép xuất báo cáo bài tập cá nhân dạng file JSON để làm bằng chứng nộp bài.

## 🚀 Hướng Dẫn Chạy Dự Án Local

1. Mở thư mục `my-new-project` trên trình duyệt web bất kỳ hoặc mở qua **Live Server** trong VS Code.
2. Hoặc mở file `index.html` trực tiếp để trải nghiệm ứng dụng.
